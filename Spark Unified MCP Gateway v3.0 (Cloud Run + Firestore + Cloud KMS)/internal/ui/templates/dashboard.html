Connector Setup & Configuration

1
Generate GitHub Personal Access Token
Open github.com/settings/tokens/new in a new tab.
2
Select Scopes
Select repo and read:user scopes (or minimal scopes for read-only repository inspection).
3
Paste Token & Connect
Paste the generated token below and click Save & Connect GitHub.
1
Register GitHub OAuth App
Open github.com/settings/applications/new.
2
Set Application URLs
Set Homepage URL to your service URL:
{{.ServiceURL}}
Set Authorization callback URL to:
{{.ServiceURL}}/oauth/callback/github
3
Paste Client Credentials
Generate a Client Secret and paste both values below.
1
Open Atlassian Developer Console
Visit developer.atlassian.com/console/myapps/.
2
Create OAuth 2.0 (3LO) Integration
Click Create → OAuth 2.0 integration and name it Spark MCP Gateway.
3
Configure Permissions & Callback
Under Permissions → Jira API, add read:jira-work and read:jira-user. Under Authorization, set Callback URL:
{{.ServiceURL}}/oauth/callback/jira
4
Save & Connect
Copy your Client ID and Secret from Settings, paste below, and connect.
